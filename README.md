# Portfolio Nguyễn Minh Anh

**Mở:** nhấp đúp `index.html`. Không cần cài đặt hay chạy server.

**Sửa nội dung:** mở `data/portfolio-data.js` (tên, số liệu, dự án, kinh nghiệm, nhận xét, liên hệ), lưu rồi tải lại trang.

| Muốn đổi | Sửa ở đâu |
|---|---|
| Email, LinkedIn | `profile` trong `data/portfolio-data.js` |
| Số điện thoại cho nút Liên hệ (Zalo, WhatsApp, Gọi) | `phone` trong `profile`. Có thể nhập số riêng cho `zalo` và `whatsapp`, để trống thì dùng `phone`. Hiện là +84 907 797 767 |
| Ảnh chân dung | Thay `assets/img/avatar.jpg` (giữ tên, tỉ lệ dọc 4:5) |
| Ảnh dự án | Thay các file `assets/img/project-*.jpg` |
| CV tải về | Thay `assets/CV_Nguyen_Minh_Anh.pdf` |
| Ghi chú cuối trang | `footerNote` trong file dữ liệu |

**Đưa lên mạng (tuỳ chọn):** kéo cả thư mục `portfolio/` vào Netlify Drop hoặc đẩy lên GitHub Pages. Khi đó cập nhật `og:image` trong `index.html` thành địa chỉ đầy đủ để link chia sẻ có ảnh xem trước.

Giao diện tự theo chế độ sáng/tối của máy; có nút chuyển ở góc trên.
